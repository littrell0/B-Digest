## 三个使用角度

**1. 有几个视频，我看了标题感兴趣，但懒得看完。** → 请使用 **【视频链接】**

**2. 我想看看我关注的UP主更新了些什么，但懒得看完。** → 请使用 **【我的关注】**

**3. 我想找一些资料/搜索一些视频，但懒得看完。** → 请使用 **【关键词搜索】**

是的，聪明的你已经发现了——前提是你懒得看完（当然也可以是没时间看完，总之你无法看完）。这就是本应用存在的意义：视频里1分钟的话，你几秒就能看完。

---

## 【我的关注】怎么用？

其他的两个很好理解，所以接下来主要讲一下 **【我的关注】** 板块。

**你需要在设置中填入B站账号的 Cookie**（Cookie 怎么弄到？看下面第 5 点），然后回到【我的关注】板块，点击登录。

很显然，不是每一个你关注的UP主你都「懒得看」——有些看的本身就是视频过程。所以你可以筛选UP主，看看哪些是你感兴趣又懒得看完的，让本应用帮你**省流**。

别的按钮都很好理解，不多介绍。

## 其他说明

### 1. 视频链接

你可以输入最多10个视频链接，应用会逐个处理。

### 2. 关键词搜索

其实就和你在B站内的搜索一样。搜出来的结果，选取你想要的，然后点击批量处理选中就可以了。其实如果你不嫌麻烦，亲自去B站搜索，把链接粘贴到【视频链接】是完全一样的逻辑（其实也没麻烦到哪去）。

### 3. AI 问答

这里是你之前处理过的视频（如果你刚下载，这里应该空空如也），你可以选取几个，然后来问 AI。这里的 AI 模型就是设置里你选取的模型。

你可能会问：这有什么d用吗？有的兄弟，有的。举个很简单的例子——比如我们搜索某游的最新更新公告和解读，不同的 UP主会有不同的解读。假如你之前处理了好几个此类视频，你可以直接问 AI 这些 UP主观点的异同。这个板块在你处理了越多视频以后，就会越有用，懂的都懂。

### 4. 设置

设置里的AI模型，纯粹是干文字总结和问答工作的，视频语音处理并不是你此处选择的AI做的——所以你随便选，这些模型全都绰绰有余。

浅色模式目前我不满意，还有些显示bug。未来短期内暂时也没有完善的想法，先摆烂了。

### 5. Cookie 获取

**浏览器 → F12 → Application → Cookies**

其实 Cookie 只用于获取你关注的 UP主（即【我的关注】板块），如果不打算登录账号，你完全没有必要填。

### 6. 系统配置

本应用是为windows做的，没有在其他系统上测试过，但是基本可以确定是不兼容的。

建议win10及以上系统
