# B站省流助手

输入B站视频链接，自动获取字幕或语音识别，通过 AI 生成完整逐字稿 + 内容概述。支持关注 UP主更新、关键词搜索、AI 问答。

## 安装启动

1. 解压 `BiliVideoSummarizer.zip` 到任意目录
2. 双击 `BiliVideoSummarizer.exe`
3. 设置页填入 API Key（三选一，去对应网站注册获取）：

| 模型 | 费用 | 注册地址 |
|------|------|---------|
| 智谱 GLM-4-Flash | **永久免费** | open.bigmodel.cn |
| 通义千问 Qwen-Plus | 月送 500 万 Token（免费） | dashscope.aliyun.com |
| DeepSeek V3 | 近乎免费（¥1/M Token） | platform.deepseek.com |

4. 语音识别模型已自带（`models/` 目录），无需额外下载。

## 五个 Tab 怎么用

### 视频链接

粘贴一个或多个 B站视频链接，逐个处理。

1. 把视频链接粘贴到输入框
2. 点 **「继续输入」**，获取视频标题和 UP主
3. 重复第 1-2 步，把想处理的视频加入队列（**最多 10 个**）
4. 点 **「开始处理」**，逐个生成逐字稿和 AI 概述

队列中的每个视频都可以点 ✕ 删除。处理过程中有两条进度条——上面显示整体进度，下面显示当前视频的实时状态。可随时点「停止」。

输出位置：`output/<UP主名>/<视频标题>/`

### 我的关注

登录 B站后，一键检测关注的 UP主最近更新了哪些视频，批量生成文字版。

1. 先在设置页填入 B站 Cookie（SESSDATA、bili_jct、buvid3），保存
2. 切换到「我的关注」→ 点 **「登录B站」**
3. 选择时间范围（6小时 ~ 7天），点 **「刷新视频列表」**
4. 系统逐 UP主检查（需等待，每个约 5-12 秒），显示新视频列表
5. 勾选要处理的视频，点 **「批量处理」**

附加功能：
- **UP主筛选**：排除不需要归纳的 UP主，后续刷新自动跳过
- **已处理标记**：之前处理过的视频显示绿色 ✓，默认不勾选
- **搜索过滤**：输入关键词过滤视频列表
- 遇到 B站限流时自动重试，无需手动干预

### 关键词搜索

不用浏览器，直接在 App 内搜索 B站视频。

1. 输入关键词，选择时长筛选（全部 / 10分钟以下 / 10-30分钟 / 30-60分钟 / 60分钟以上）和日期筛选（全部 / 最近一天 / 最近一周）
2. 选择视频数量（5 / 10 / 20）
3. 点 **「搜索」**
4. 勾选视频，点 **「批量处理」**

搜索不需要登录。建议每次搜索间隔 30 秒，避免频繁请求。

### AI 问答

基于已处理过的视频向 AI 提问。

1. 左侧显示所有处理过的视频，按 UP主分组（点击展开/折叠）
2. 勾选一个或多个视频
3. 在右侧输入问题，按 Enter 发送
4. AI 根据勾选视频的内容回答

支持多选——比如勾选 3 个 UP主对同一事件的解读，问「他们的观点有什么不同？」。对话有上下文记忆，可追问。点击「新对话」重置，点击「保存对话」导出为 Markdown。

### 设置

所有调整都在这里：

- **AI 模型**：三选一（DeepSeek / 通义千问 / 智谱），选择后会看到准确度和速度评分
- **识别精确度**：四档（最精确 / 精确 / 普通 / 急速），控制语音识别的模型大小
- **概览详细程度**：精细 / 大致 / 极简，控制 AI 概述的字数
- **输出格式**：Markdown（带格式）或 TXT（纯文本）
- **语音识别模型**：点击「下载模型」下载到本地
- **界面**：深色 / 浅色主题（浅色模式测试中）
- **B站账号**：填写 Cookie 供「我的关注」使用
- **查看运行日志**：有故障时点此查看 `app.log`

## 识别精确度

处理无字幕的视频时，使用本地的 faster-whisper 模型进行语音识别。四个档位：

| 预设 | 模型 | 精确度 | 速度 (每1分钟视频) | 适合 |
|------|------|:-----:|:----:|------|
| 最精确 | large-v3 | 95% | 3.0 分钟 | 专业字幕、重要归档 |
| 精确 | medium | 88% | 1.5 分钟 | 学习笔记 |
| 普通 | small | 75% | 0.5 分钟 | 快速浏览 |
| 急速 | tiny | 60% | 0.2 分钟 | 预览（不推荐中文） |

纯本地运行，不联网，不花钱。有字幕的视频不需要语音识别，直接提取字幕即可。

## 概览详细度

控制 AI 输出的字数比例：

| 级别 | 占原文 | 10分钟视频约 | 适合 |
|------|--------|-------------|------|
| 精细概览 | 25-35% | 750-1200字 | 深度笔记 |
| 大致概览 | 10-15% | 300-500字 | 日常浏览 |
| 极简概览 | ≤5%（≤200字） | 100-200字 | 快速筛选 |

## B站 Cookie 获取

仅「我的关注」需要。获取方法：

1. 用 Edge / Chrome 打开 bilibili.com 并登录
2. 按 **F12** 打开开发者工具
3. 点击顶部的 **Application**（应用程序）标签
4. 左侧 **Storage → Cookies → https://www.bilibili.com**
5. 找到三个字段，复制 Value 那一列：
   - `SESSDATA`（以 `%2C` 结尾）
   - `bili_jct`
   - `buvid3`
6. 粘贴到设置页 → 保存

## 常见问题

**Q: 语音识别太慢？**
A: 设置页把「识别精确度」改成「普通」或「急速」。

**Q: AI 概述太长/太短？**
A: 设置页改「概览详细程度」。

**Q: 想用免费的 AI？**
A: 设置页 → AI 模型 → 选「glm-4-flash」→ 去 open.bigmodel.cn 注册拿 Key。

**Q: 批量处理登录失败？**
A: Cookie 没复制全，特别是 SESSDATA 要以 `%2C` 结尾。

**Q: 批量处理显示「系统限流」？**
A: B站访问频率限制，正常现象。软件会自动等一下重试。

**Q: 搜索提示「request was banned」？**
A: 短时间内搜太多次，等一会再搜。

**Q: 没有语音识别模型？**
A: 只影响无字幕的视频。有字幕的视频不需要模型。去设置页点「下载模型」即可。
